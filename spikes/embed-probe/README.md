# embed-probe — спайк встраивания окон

Одноразовый код к этапу 1 из [docs/PLAN.md](../../docs/PLAN.md): проверяем,
работает ли overlay-встраивание чужих окон на Windows 11. Код намеренно
грязный (один файл, `unsafe` везде, ручной FFI) — в основной код не переносится,
переносятся только выводы (в `docs/embedding.md`).

## Что умеет

- Слева сессия `probe` (`WFOXD_SESSION=probe`, cwd = `%USERPROFILE%`) и кнопки
  запуска: cmd через conhost, cmd как есть, Блокнот, Paint, Проводник,
  Таблица символов, PowerShell через conhost.
- Каждое приложение запускается `CreateProcessW` с окружением сессии в своём
  Job Object и встраивается overlay'ем: owned-окно поверх рабочей области,
  неактивные табы спрятаны.
- Поиск окна: сначала среди процессов Job, иначе — новое видимое окно, которого
  не было до запуска (Store-приложения Win11, Explorer). Ещё 3 с после
  встраивания следим за запуском и забираем дополнительные окна в отдельные табы.
- Переключатель «Рамку окна: снимать / оставлять» — для следующих запусков.
  В режиме «оставлять» стили окна не трогаем, учитываем невидимые поля DWM
  (`DWMWA_EXTENDED_FRAME_BOUNDS`).
- Клик по табу — переключить, × — закрыть (`WM_CLOSE`), ПКМ — отцепить.
  Закрытие главного окна отцепляет все окна; красная кнопка —
  `TerminateProcess` самого себя (тест «мы упали»).
- Лог `wfoxd-probe.log` рядом с exe (или в `%TEMP%`): каждое новое окно после
  запуска (hwnd, процесс, класс, стили, owner), решения, отцепления.

## Сборка

На Linux (Debian/Ubuntu/Mint):

```sh
sudo apt install mingw-w64 wine64          # + xvfb, если без дисплея
rustup target add x86_64-pc-windows-gnu
cargo build --release --target x86_64-pc-windows-gnu
cargo run   --release --target x86_64-pc-windows-gnu   # через wine
```

На Windows: `cargo build --release` (MSVC-таргет тоже подходит).

## Что проверять на Windows 11

1. Какие приложения встраиваются; что пишет лог, когда появляется лишнее окно.
2. Ресайз/перемещение/сворачивание главного окна, второй монитор, масштаб 125–150 %.
3. Фокус и ввод во встроенном окне, переключение табов.
4. Отцепление (ПКМ и закрытие главного окна) в обоих режимах рамки —
   нормально ли перерисовывается рамка.
5. Красная кнопка: выживают ли встроенные приложения.
6. Лишние кнопки на панели задач.
